# Push-уведомления Niet Café — настройка (≈15 минут, один раз)

**Что получится:** уведомления приходят на телефон/компьютер даже при закрытом приложении и заблокированном экране.

| Кому | Когда |
|---|---|
| Кухня / Бар | 🔔 новый заказ · ❌ официант убрал позицию |
| Официант | 👍 принято · ✅ готово (только по своим заказам) |

Если приложение открыто на экране — работает как раньше (окно + звук), системное уведомление не дублируется.

## Шаг 1. Ключи
Откройте `vapid-keys.html` двойным щелчком → «Создать ключи». Получите **публичный** и **приватный** ключ.
Публичный вставьте в `index.html`: `const VAPID='ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ';`

## Шаг 2. Edge Function
Supabase → **Edge Functions → Deploy a new function** → имя `push` → вставьте код из `supabase/functions/push/index.ts`.
**Обязательно выключите «Verify JWT»** (защита — секрет, шаг 3).

Затем **Edge Functions → Secrets** добавьте четыре значения:

| Имя | Значение |
|---|---|
| `VAPID_PUBLIC` | публичный ключ |
| `VAPID_PRIVATE` | приватный ключ |
| `VAPID_SUBJECT` | `mailto:ваш@email.kz` |
| `PUSH_SECRET` | любая длинная случайная строка (придумайте сами) |

## Шаг 3. База данных
SQL Editor → выполните `7_push.sql` целиком. Затем отдельным запросом впишите тот же секрет:

```sql
update push_cfg set val='ТОТ_ЖЕ_PUSH_SECRET' where key='secret';
```

## Шаг 4. Выложите обновлённые `index.html` и `sw.js`

## Шаг 5. Включите на каждом устройстве
Войдите под сотрудником → нажмите жёлтую полосу «🔔 Включить звук и уведомления» (или кнопку 🔔 в шапке) → **Разрешить**. Должно появиться «✅ Push включён».

- **iPhone/iPad (iOS 16.4+):** сначала в Safari «Поделиться» → **«На экран Домой»**, открывайте приложение с иконки, потом включайте. В обычной вкладке Safari push не работает.
- **Android / компьютер (Chrome, Edge):** работает сразу, в том числе из обычной вкладки.
- Если нажали «Блокировать» — разрешите уведомления в настройках браузера для сайта.
- На общем планшете: при «Выйти» подписка устройства снимается, следующий сотрудник включит свою.

## Проверка
```sql
select push_send('[{"kind":"test","to_role":"waiter","tag":"test","title":"Тест","body":"Push работает"}]'::jsonb);
```
Придёт всем официантам с включёнными уведомлениями. Затем создайте тестовый заказ.

## Если не приходит
1. Edge Functions → `push` → **Logs**: нет записей — не совпадает секрет (`push_cfg` и `PUSH_SECRET`) или включён Verify JWT. Ошибка 403 — тоже секрет.
2. `select count(*) from push_subs;` — 0 значит устройство не подписалось (шаг 5).
3. Android: отключите «экономию батареи» для браузера/приложения.
4. Ключи VAPID пересоздавали — подпишите устройства заново.

Сбой отправки никогда не мешает принимать заказы: все ошибки push в базе подавляются.

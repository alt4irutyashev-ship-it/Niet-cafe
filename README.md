# Niet Café — система учёта и гостевое меню

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Приложение для персонала: официант, кухня, бар, руководитель |
| `guest.html` | Гостевая страница для NFC-меток: меню, вызов официанта, заказ с телефона |
| `1_schema.sql` … `14_flow_history.sql` | База данных: выполнялись по порядку номеров (файлы `5_…` и `6_…` по два — оба нужны) |
| `migration.sql`, `migration2.sql`, `migration3.sql` | Старые миграции. **Повторно не запускать** — `migration3.sql` снимает защиту склада |
| `17_market_prices.sql` | Рыночные цены на продукты (Астана, ноябрь 2026) — **только предпросмотр**, ничего не меняет |
| `18_apply_prices.sql` | Применяет цены из шага 17 (только строки «обновится») |
| `19_fixes.sql` | Исправление формулы потерь в себестоимости и списании + закрытие лишних прав |
| `ЦЕНЫ_2026-11.md` | Таблица цен с источниками |
| `7_push.sql`, `PUSH_SETUP.md`, `supabase/functions/push/` | Push-уведомления (`push-edge-function.ts` — копия той же функции) |
| `sw.js`, `manifest.json`, `guest.webmanifest`, иконки | Установка на телефон и работа без интернета |

Файлы `15_recipes_products.sql` и `16_loss_overheads.sql`, упомянутые раньше, в репозитории отсутствуют.

### Обновление цен (раз в 1–2 месяца)
1. SQL Editor → выполнить `17_market_prices.sql` → посмотреть таблицу.
2. Строки «проверьте вручную» и «нет рыночной цены» поправить руками в приложении (Склад → продукт).
3. Выполнить `18_apply_prices.sql`. Старые цены сохраняются в истории цен продукта.
4. Выполнить `19_fixes.sql` (один раз; повторно безопасно).

## Установка

1. Supabase → SQL Editor: если база новая — выполнить `1_schema.sql`, затем `2_menu.sql`.
2. Выполнить `4_update.sql`, `5_guest.sql`, затем `6_update.sql` (их можно запускать повторно).
3. В `index.html` и `guest.html` вписать адрес и ключ Supabase в строке `const URL_=…,KEY=…`
   (Project Settings → API: Project URL и anon public key).
4. В Supabase → Authentication отключить подтверждение email (вход по логинам `@niet.cafe`).
5. Загрузить ВСЕ файлы в GitHub (включая sw.js, manifest и иконки) — Render обновит сайт.
   При следующих обновлениях сайта увеличьте версию в первой строке `sw.js` (niet-v1 → niet-v2), чтобы телефоны подхватили новое.
6. По желанию: положить логотип в репозиторий как `logo.png` — он появится на гостевой странице.

## Что умеет

**Официант** — схема зала (9 столов, вход справа сверху), заказ, комментарии к блюдам для кухни,
10% обслуживания, пречек, перенос и объединение столов, оплата наличными / картой / Kaspi / смешанная,
уведомление «блюдо готово», стоп-лист.

**Кухня и бар** — заказы карточками по столам (краснеют через 15 мин), комментарии, техкарты, стоп-лист.

**Склад** — остатки, приход, выдача, списание с причиной, инвентаризация, минимальные остатки, журнал.

**Руководитель** — отчёты (выручка, обслуживание, прибыль, средний чек, оплаты, официанты, по часам и
дням недели, «заканчивается»), заказы, меню (цены, новые блюда, состав, фото, стоп), техкарты с
себестоимостью и фудкостом, вкладка «Гостям» (ссылки TikTok / Instagram / WhatsApp / 2ГИС и ссылка для
NFC), склад, сотрудники, затраты.

**Язык** — переключатель РУС / ҚАЗ.

## Гостевая страница (NFC)

Ссылка: адрес сайта + `/guest.html` (её видно во вкладке «Гостям» у руководителя).
Записать на метку: приложение NFC Tools → Записать → URL. Одна ссылка подходит для всех столов,
её же можно сделать QR-кодом.

### Ссылки на столы
У каждого стола своя ссылка `guest.html?t=НОМЕР` (готовый список — у руководителя во вкладке «Гостям»).
По ней гость может позвать официанта, попросить счёт и отправить заказ — у официанта сразу всплывает уведомление.
Общая ссылка без номера — просто меню (для QR на входе или в Instagram).

## Иконка на телефоне
Откройте сайт в Safari (iPhone) → «Поделиться» → «На экран Домой»; в Chrome (Android) → меню → «Установить приложение».
Иконка временная (буква N). Положите `logo.png` и замените `icon-192.png` / `icon-512.png` своим логотипом.

## Без интернета
Официант продолжает принимать заказы: они копятся в очереди и отправляются сами, когда связь вернётся.
Оплата и закрытие стола — только с интернетом. Гости видят меню, если уже открывали его раньше.
